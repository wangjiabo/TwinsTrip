# 🛰️ TwinTrip — 双胞胎带娃出游作战指挥系统

> 名字来源：**Twin**（双胞胎）+ **Trip**（出行）
> 简称：**TT**（Twin Trip）
> Slogan：**带两个娃出门，像指挥一场战役**

---

## 📖 关于 TwinTrip

TwinTrip 是一个专为**双胞胎/多子女家庭**设计的出游规划与实时作战指挥系统。

普通的旅行规划器面向"人"，TwinTrip 面向"**娃**"。它把带娃出游这件事，当作一场**多节点、高不确定性、资源受限的指挥控制任务**来处理。

### 我们的目标用户

- 双胞胎/多子女家庭的父母
- 宝宝年龄 0-3 岁（MVP 阶段聚焦 8-12 个月）
- 未来随着宝宝成长逐步扩展功能

### 核心设计理念

| 指挥控制 | TwinTrip 对应 |
|---------|--------------|
| 作战计划 OPlan | 动态时间窗行程规划 |
| 资源调度 | 双娃同步的作息管理 |
| 补给清单 | 智能物品清单（含冗余计算）|
| 应急处置预案 | 突发事件实时处置 |
| 延误管理 | 喂奶/拉臭臭延误自动重排 |
| 态势感知 | 地图上实时看紧急资源 |
| 双人协同 | 爸爸/妈妈双终端同步 |

## ✨ MVP 核心功能（当前阶段）

### ⏰ 动态时间窗行程规划
- 不是 "9:00 到景点A"，而是 "9:00-10:00 窗口内到达"
- 内置 8 个月宝宝作息模板（可自定义）
- **双娃时间差**感知：自动计算两个娃的 nap/喂奶时间重叠窗口

### 📦 智能物品清单（作战物资管理）
- 双胞胎模板：纸尿裤 8片/人 → 自动算 16片 + 20% 冗余 = 19片
- 物品场景关联：去公园 → 自动勾选防蚊液 + 遮阳帽 + 野餐垫
- 动态库存：上次用了多少 → 下次自动建议带多少
- 分类：**必须带（忘了就完蛋）** vs **可选带（看情况）**

### 🚨 突发事件实时处置
- 事件触发 → 自动排程重算：喂奶超时 20min → 后续节点全部自动调整
- 紧急程度标记：🔴 拉臭臭 → 最近母婴室；🟡 饿了 → 附近喂奶点；🟢 困了 → 休息点
- 一键降级预案：原计划景点 → 延误后自动建议附近替代

### 📍 态势感知地图
- 一个地图：当前位置 + 已规划路线 + 喂奶点 + 母婴室 + 儿科/药店
- 实时计算："距离下次喂奶还有 45 分钟，距离最近喂奶点 2.3km"
- 紧急资源点颜色标记

### 👨‍👩‍👧‍👦 双终端协同
- 爸爸/妈妈两个手机实时同步
- 分工模式：爸爸管路线，妈妈管宝宝状态
- 妈妈标记"老大拉了" → 爸爸端自动弹出母婴室导航

## 🏗️ 技术架构

```
┌─────────────────────────────────────────────────┐
│                  前端 (微信小程序)                │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ ┌───────┐  │
│  │ 首页  │ │行程  │ │清单  │ │地图  │ │应急处置│  │
│  └──┬───┘ └──┬───┘ └──┬───┘ └──┬───┘ └───┬───┘  │
│     └────────┴────────┴────────┴─────────┘      │
│                      ↓ HTTP/WebSocket            │
├─────────────────────────────────────────────────┤
│                   后端 API (Node.js)             │
│  ┌──────────┐ ┌──────────┐ ┌────────────────┐   │
│  │ 行程规划  │ │ 物资管理  │ │ 应急处置引擎    │   │
│  └──────────┘ └──────────┘ └────────────────┘   │
│                      ↓                           │
│              PostgreSQL + Redis                   │
└─────────────────────────────────────────────────┘
```

- **前端**：微信小程序（原生 + TypeScript）
- **后端**：Node.js + Express + TypeScript
- **数据库**：PostgreSQL
- **部署**：Vercel (后端) + 微信平台 (小程序)
- **地图**：腾讯地图 SDK（小程序原生支持）

## 🛠️ 快速开始

### 后端

```bash
cd server
npm install
npm run dev
```

### 小程序

1. 下载[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 导入 `miniapp/` 目录
3. 在 `app.json` 中填入你的腾讯地图 Key
