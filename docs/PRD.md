## 1. 产品背景

### 1.1 问题陈述

带一对8个月大的双胞胎出门，是一种**多节点、高不确定性、资源受限的指挥控制任务**：

1. **时间是最稀缺的资源**：两个娃的喂奶、nap、拉臭臭时间可能不同步，计划随时被打乱
2. **物资容错率为零**：忘了带一片纸尿裤、一瓶奶粉，都可能演变成一场危机
3. **决策压力巨大**：在陌生环境中，突发状况需要在几秒内做出正确决策
4. **信息不对称**：不知道附近哪有母婴室、儿科、能喂奶的地方

现有旅行规划器（携程、攻略、Google Maps）面向"健康成年人"，完全不考虑带娃的特殊性。

### 1.2 目标用户画像

| 属性 | 描述 |
|------|------|
| 身份 | 双胞胎/多子女父母 |
| 宝宝年龄 | 8-12 个月（MVP）|
| 主要场景 | 周末公园游、周边城市自驾、探亲 |
| 设备 | 爸爸 + 妈妈各一台手机（微信小程序）|
| 痛点优先级 | 作息冲突 > 物资忘记带 > 突发找不到资源 > 路线不合理 |

### 1.3 成功指标（MVP）

- 用户能在 5 分钟内完成一次出游行程规划
- 系统自动识别并标注 8 个月宝宝的作息时间窗
- 物品清单覆盖率 ≥ 90%（基于真实场景验证）
- 应急响应时间 < 5 秒（触发到地图显示最近资源点）

## 2. 功能需求（MVP）

### 2.1 首页 — 态势感知总览

**目标**：一眼看清当前出游状态，像指挥中心的态势大屏。

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|--------|
| H-01 | 双娃状态卡片 | 同时显示两个宝宝的当前状态（清醒/睡觉/上次喂奶时间/上次拉臭臭时间）| P0 |
| H-02 | 紧急时间提醒 | 倒计时显示："距离下次喂奶还有 X 分钟"、"距离预计 nap 还有 X 分钟"| P0 |
| H-03 | 当前位置 + 附近资源 | 地图小窗显示当前位置 + 最近的母婴室/儿科/药店 | P0 |
| H-04 | 今日行程进度 | 时间轴显示今日已完成/进行中/待执行的行程节点 | P1 |
| H-05 | 快速操作入口 | 一键标记"喂奶中""拉臭臭了""开始 nap" | P0 |

### 2.2 行程规划模块

**目标**：动态时间窗式的智能行程排期，自动适配宝宝作息。

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|--------|
| I-01 | 双娃作息模板 | 内置 8 个月宝宝典型作息（6:30 起床 → 8:00 上午 nap → 12:00 午饭 → 14:00 下午 nap → 18:00 晚饭 → 20:00 睡觉）| P0 |
| I-02 | 自定义时间窗 | 用户可手动调整每个节点的时间窗口 | P0 |
| I-03 | 拖拽排期 | 类似日历的拖拽界面，把景点/活动拖到某个时间窗 | P1 |
| I-04 | 时间冲突检测 | 自动检测行程节点是否落在宝宝的 nap/喂奶时间，标红警示 | P0 |
| I-05 | 双娃时间差感知 | 如果两个宝宝作息不同步，自动建议"两者都清醒"的窗口 | P1 |
| I-06 | 延误自动重排 | 标记"喂奶超时 20min"后，后续所有节点自动重新计算时间 | P0 |
| I-07 | 路线距离计算 | 自动计算两个地点之间的距离和驾车时间 | P0 |

### 2.3 物品清单模块

**目标**：双胞胎作战物资管理，带多了累，带少了要命。

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|--------|
| C-01 | 双胞胎数量自动计算 | 输入单人需求量，自动 ×2 + 冗余系数 | P0 |
| C-02 | 场景模板 | 按出游场景提供推荐清单（公园、海边、自驾、飞机）| P0 |
| C-03 | 物品分类 | 必须带 vs 可选带；按类别分：喂奶、换尿布、衣物、应急药 | P0 |
| C-04 | 动态冗余 | 根据出行时长和距离，自动计算冗余量（出行 >2h 时纸尿裤 ×1.5）| P1 |
| C-05 | 历史库存 | 记录上次出游带了什么、用了多少，下次自动建议 | P2 |
| C-06 | 打包勾选 | 出门前逐项勾选打包完成状态 | P0 |

### 2.4 应急处置模块

**目标**：突发状况下的秒级决策辅助。

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|--------|
| E-01 | 突发事件快速标记 | 四个大按钮：🔴 拉臭臭、🟡 饿了、🟢 困了、🟣 突发状况 | P0 |
| E-02 | 自动定位最近资源 | 根据事件类型，地图自动高亮显示最近的母婴室/喂奶点/休息点 | P0 |
| E-03 | 一键导航 | 点击资源点，拉起腾讯地图/高德地图导航 | P0 |
| E-04 | 应急联系卡 | 显示附近儿科电话、药店电话、紧急联系人 | P0 |
| E-05 | 行程降级建议 | 延误超过阈值 → 自动建议附近替代景点 | P1 |
| E-06 | 情况报告模板 | 结构化记录事件：时间、地点、发生了什么、怎么处理的（供未来参考）| P2 |

### 2.5 态势感知地图

**目标**：一张地图看清一切。

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|--------|
| M-01 | 多层资源点叠加 | 喂奶点（蓝）+ 母婴室（粉）+ 儿科/药店（红）+ 加油站（黄）| P0 |
| M-02 | 路线规划叠加 | 已规划的行程路线叠加在地图上 | P1 |
| M-03 | 实时距离显示 | 点击任意资源点，显示距离 + 预计到达时间 | P0 |
| M-04 | 当前位置到下一点 | 用雷达图显示"距离下一个喂奶点 X km" | P0 |

### 2.6 宝宝档案

**目标**：记录两个宝宝的基础数据。

| 编号 | 功能 | 描述 | 优先级 |
|------|------|------|--------|
| B-01 | 双宝宝资料 | 姓名、出生日期、身高体重、过敏史 | P0 |
| B-02 | 作息历史 | 记录每日喂奶/nap/拉臭臭时间，用于个性化模板 | P1 |
| B-03 | 月龄成长适配 | 根据宝宝月龄，自动推荐适用的物品和活动 | P1 |

## 3. 非功能需求

| 编号 | 需求 | 描述 |
|------|------|------|
| NF-01 | 离线可用 | 地图和清单支持离线缓存，地下车库等无信号区域也能用 |
| NF-02 | 响应速度 | 应急处置从触发到显示结果 < 5 秒 |
| NF-03 | 数据同步 | 双终端数据同步延迟 < 3 秒 |

## 4. 用户故事

### US-01: 周末公园游规划

> 作为双胞胎宝爸，我想在周五晚上花 5 分钟规划周六的公园游，这样我和老婆都不用临时手忙脚乱。
>
> 1. 打开 TwinsTrip
> 2. 点击"新建行程" → 选择"周末公园游"模板
> 3. 系统自动填充：9:00-9:30 出门 → 9:30-10:00 自驾 → 10:00-12:00 公园（避开老大 11:00 的 nap）
> 4. 系统自动生成物品清单：纸尿裤 16片 + 冗余 4片 = 20片，奶粉 2瓶，口水巾 8条...
> 5. 我手动调整时间窗为 9:00-9:15 出门（留缓冲）
> 6. 推送行程到老婆的手机

### US-02: 喂奶延误自动重排

> 作为双胞胎宝妈，老大 11:00 要 nap，刚才喂奶多花了 15 分钟，我想系统自动帮我重新安排下午的行程。
>
> 1. 在首页点击"喂奶中"（实际花了 25 分钟，比预计多 15 分钟）
> 2. 系统自动检测到 nap 时间冲突
> 3. 弹出建议："建议将公园停留时间缩短 30 分钟，并跳过计划中的午餐外食"
> 4. 我点击"确认"
> 5. 爸爸的手机上行程自动同步更新

### US-03: 紧急找母婴室

> 作为双胞胎宝爸，老大突然拉臭臭了，我想立刻找到最近的母婴室。
>
> 1. 单手点击首页的红色🔴按钮
> 2. 地图瞬间切换到"母婴室模式"，高亮显示最近的 3 个母婴室
> 3. 第一个 0.8km，预计 5 分钟到达
> 4. 点击，拉起导航
> 5. 手机震动 + 语音提示："已规划到最近母婴室的路线"

### US-04: 物品清单打包

> 作为双胞胎宝妈，出门前我想快速核对打包清单，确保没落下什么。
>
> 1. 打开清单页面，看到系统按"公园游"模板生成的 42 项物品
> 2. 双胞胎用量已自动翻倍
> 3. 我逐项勾选已打包的物品
> 4. 发现"奶瓶"还没勾选，系统红色提醒"忘了就完蛋！"
> 5. 打包完成后，清单状态变为✅绿色
